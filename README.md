# Lumo — сайт

Лендинг мессенджера **Lumo**: «Свои люди. Одно место.»

Статический сайт без сборки — `index.html`, картинки в `img/`, шрифт Inter в `fonts/`.
Публикуется через GitHub Pages из ветки `main`.

## Посмотреть у себя

```
C:\flutter\bin\cache\dart-sdk\bin\dart.exe tools/serve.dart
```

и открыть http://localhost:8643.
